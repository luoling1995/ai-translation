## 六、验证计划

### 开发阶段验证

1. 在 `chrome://extensions/` 中以开发者模式加载插件
2. **划词翻译验证**：
   - 打开任意英文网页，选中一段英文文本 → 翻译按钮出现在选区附近
   - 点击翻译按钮 → 浮窗出现，显示加载状态 → 在 30 秒超时前显示中文译文或错误提示
   - 点击浮窗外部 → 浮窗关闭
   - 按 Esc → 浮窗关闭
   - 选中超过 5000 字符的文本 → 不出现翻译按钮
   - 选中中文文本 → 翻译按钮出现，点击后翻译结果为原文
3. **右键菜单验证**：
   - 选中文本后右键 → 菜单中出现"翻译选中文本"
   - 点击"翻译选中文本" → 页面中心出现翻译浮窗
   - 页面空白处右键 → 菜单中出现"翻译整个页面"
4. **整页翻译验证**：
   - 打开英文页面 → Popup 中点击"翻译当前页面" → 进度条出现 → 文本逐步被替换为中文
   - 翻译完成后点击"恢复原文" → 所有文本恢复
   - 翻译进行中点击"取消" → 翻译停止
   - 打开中文页面 → 整页翻译 → 提示"页面无需翻译"
5. **动态内容翻译验证**：
   - 打开 X.com（或任意无限滚动页面）→ 触发整页翻译 → 翻译完成
   - 向下滚动加载新内容 → 新加载的推文/内容自动被翻译（约 500ms 延迟后开始）
   - 点击"恢复原文" → 所有内容（包括动态加载的）恢复原文 → 继续滚动不再自动翻译
   - 快速连续滚动 → 不应出现重复翻译或报错
6. **设置页验证**：
   - 输入 API Key → 保存 → 关闭 Popup → 重新打开 → API Key 已保存
   - 输入错误的 API Key → 测试连接 → 显示"API Key 无效"
   - 不输入 API Key → 测试连接 → 提示"请先输入 API Key"
   - 修改模型名为其他 MiniMax 模型 → 保存 → 翻译正常使用新模型
7. **边界条件验证**：
   - 未配置 API Key 时触发翻译 → 浮窗显示提示配置 Key
   - 断网时翻译 → 显示"网络连接失败"
   - 在 Google、GitHub 等不同网站上测试划词翻译 → 浮窗样式不被页面 CSS 影响
8. **构建验证**：
   - `npm run typecheck` 类型检查无错误
   - `npm run build` 成功生成 `dist/background.js`、`dist/content.js`、`dist/popup.js`
   - 生成的三个 JS 文件中不包含运行时 `import` / `export`
   - Chrome 加载 `dist/` 目录能正常运行
